# Plans

Multi-step efforts. Each plan is a numbered markdown file; progress on the
active plan is tracked in [progress.md](progress.md).

| # | Plan | Status |
|---|------|--------|
| [0001](0001-rearchitecture.md) | Re-architect repo (platform split, inventory, sops-nix, tooling) | in progress |

Conventions:

- A plan describes *intent*; decisions it produces become ADRs.
- `progress.md` is the living log: phase checklist, verification evidence,
  follow-ups. Update it in the same commit as the work.
